# Bounded method experiment

Before execution, complete only Decision and baseline and Frozen comparison using available evidence. Complete Actual run after execution and Subsequent method use when later observations are available. Equivalent existing records are acceptable.

## Decision and baseline
- Real problem and original outcome:
- Evidence supporting an experiment; competing explanations:
- Current mechanism M0, recoverable version/source and actual operation:
- Candidate M1 and exact change in how improvements are generated or evaluated:
- Why this is a method change rather than only a task-output repair:
- Actor, allowed effects, scope and dependencies:

## Frozen comparison
- Comparable task inputs, tools and material conditions:
- Development versus held-out cases, if generalization is claimed:
- Observable decision/action success criteria:
- Legitimate success controls and non-regression constraints:
- Cost budget and observable cost measurement:
- Failure, stop and rollback conditions; responsible actor:

## Actual run (complete after execution)
- Loaded M0/M1 identities and input evidence:
- Actual operations, artifacts and results:
- First failures, skipped checks, mismatches and confounders:
- Benefit/regression/inconclusive comparison and cost:
- Adopt/reject/defer/rollback decision and allowed scope:
- Authorized saved record and readback:

## Subsequent method use
- Real later improvement opportunity:
- Evidence that M1 participated in producing or evaluating M2:
- M2's own criteria, actual evaluation and disposition:
- Application account saved and read back:
- Recurrence observed? Benefit demonstrated? Limits of each claim:
- Remaining validation/rollback owner and next action:

Do not fill future observations in advance. Missing later evidence is not a successful recursive link.
